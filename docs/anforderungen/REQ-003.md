## Beschreibung

In der Simulation (Wokwi, `jointsense/diagram.json`) gibt es eine orange LED mit dem Namen «Motor (Platzhalter)». Sie hängt an D9, über 220 Ω an GND. Sie zeigt an, wann der Vibrationsmotor vibrieren würde. Die Person sieht so in der Simulation sofort, ob das Gerät den Motor einschaltet. Die LED ist nur ein Platzhalter. Am echten Gerät steuert D9 den Motortreiber.

## Akzeptanzkriterien

Jedes Kriterium muss **messbar** sein (Zahl + Einheit), damit der Tester es prüfen kann.

- [ ] AK-1: Solange der Motor aus ist (D9 = 0), ist die LED aus.
- [ ] AK-2: Solange der Motor vibriert (D9 = MOTOR_STAERKE, 200 von 255), leuchtet die LED.
- [ ] AK-3: LED und Motor wechseln im gleichen Messzyklus. Verzögerung ≤ 100 ms (QA-05).
- [ ] AK-4: Die LED hängt in `diagram.json` an D9 über einen Widerstand (220 Ω), Kathode an GND. Das entspricht der README-Verdrahtung (D9 → Treiber IN1) und `pins.h` (`PIN_MOTOR_PWM = 9`).

## Schnittstelle

Keine neuen Funktionen. Das Verhalten entsteht durch die bestehenden Funktionen für den Motor in `jointsense.ino` (`analogWrite(PIN_MOTOR_PWM, …)`).
